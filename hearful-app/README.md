# 🦻 Hearful — Frontend App

Questa cartella contiene il codice sorgente dell'applicazione **Hearful** (companion app per occhiali AR rivolta alla comunità sorda).

Per la documentazione completa del progetto, l'architettura e i dettagli sull'esame di Interazione Uomo-Macchina, consulta il [README principale](../README.md).

---

## 🚀 Avvio Rapido

```bash
# Installazione dipendenze
npm install

# Avvio server di sviluppo esposto sulla rete locale (per smartphone)
npm run dev -- --host
```
